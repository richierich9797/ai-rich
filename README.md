## 项目介绍

围绕「100 天挑战 100 万」的实践，记录 AI 在跨境电商中的应用，并将实践中形成的方法整理为 Skills、工作流、提示词、模板与知识库，供大家学习和使用。

「100 天挑战 100 万」是项目挑战目标，不代表已取得的成果。具体统计口径与挑战规则将在后续说明中公布。
